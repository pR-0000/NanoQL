# QL system ROM / ROM système QL

Place no copyrighted ROM image in the repository. Run `tools/prepare_ql_rom.ps1` with a legally obtained 48 KiB or 64 KiB binary dump. The generated `ql_system_rom.hex` is ignored by Git.

Ne placez aucune image ROM protégée dans le dépôt. Lancez `tools/prepare_ql_rom.ps1` avec un dump binaire de 48 Kio ou 64 Kio obtenu légalement. Le fichier `ql_system_rom.hex` généré est ignoré par Git.

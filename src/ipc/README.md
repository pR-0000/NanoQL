# Firmware IPC QL / QL IPC firmware

Le cœur OpenCores `t48` est inclus. Utilisez `tools/nanoql_setup.py` pour convertir le firmware Sinclair standard `ipc8049.hex` fourni par le core QL MiSTer. NanoQL privilégie ce firmware d’origine pour reproduire le comportement du contrôleur 8049.

The OpenCores `t48` source is included. Use `tools/nanoql_setup.py` to convert the standard Sinclair `ipc8049.hex` firmware supplied by the MiSTer QL core. NanoQL favors this original firmware to reproduce the behavior of the 8049 controller.
